# DataLens Unified Data Import Engine

## 1. Engine Objective

The `ImportEngine` (`backend/app/services/connectors/import_engine.py`) acts as the ingestion bridge between external data sources and DataLens's analytical core.

Instead of writing intermediate raw files (such as dumping massive uncompressed CSVs to disk), the `ImportEngine` streams batches directly from connector drivers, normalizes types, writes partitioned Snappy-compressed Parquet parts, and establishes immutable `Dataset` and `DatasetVersion` entities in PostgreSQL.

---

## 2. Ingestion Lifecycle

```
[External Connector Stream] 
           │
           │ Asynchronous chunk yields (e.g., 5,000 rows/batch)
           ▼
[DatasetProcessor Type Inference]
           │
           │ Type voting & name sanitization
           ▼
[PyArrow Columnar Chunk Writer]
           │
           │ Writes datasets/{ws_id}/{dataset_id}/{version_id}/processed/part-00001.parquet
           ▼
[Manifest Generator]
           │
           │ Computes SHA-256 checksum, manifest.json
           ▼
[Immutable Version Creation]
           │
           │ Registers DatasetVersion in DB (e.g. "v1.0")
           ▼
[DuckDB Analytics & Dashboards Ready]
```

---

## 3. Storage Layout Specification

DataLens stores ingested data under an opaque, isolated directory layout:

```
storage/datasets/{workspace_id}/{dataset_id}/{version_id}/
└── processed/
    ├── part-00001.parquet
    ├── part-00002.parquet
    ├── part-00003.parquet
    └── manifest.json
```

### Manifest Structure (`manifest.json`)
```json
{
  "parts": [
    "datasets/ws-123/ds-456/v-789/processed/part-00001.parquet",
    "datasets/ws-123/ds-456/v-789/processed/part-00002.parquet"
  ],
  "row_count": 10000,
  "column_count": 8,
  "columns": [
    {
      "name": "id",
      "inferred_type": "integer",
      "null_count": 0,
      "sample_values": ["1", "2", "3", "4", "5"]
    },
    {
      "name": "revenue",
      "inferred_type": "float",
      "null_count": 12,
      "sample_values": ["120.5", "450.0", "99.95"]
    }
  ],
  "watermark_column": "updated_at",
  "watermark_value": "2026-11-12T09:30:00Z",
  "source_type": "postgres",
  "source_resource": "public.orders"
}
```

---

## 4. Column Type Inference Resolution

During ingestion streaming, `ImportEngine` maintains a type vote map across all incoming batches. When mixed types are encountered, the dominant type is chosen according to strict analytical hierarchy:

$$\text{float} > \text{integer} > \text{date/timestamp} > \text{boolean} > \text{string}$$

Heterogeneous arrays or uncoercible types safely fall back to UTF-8 strings.

---

## 5. Downstream Compatibility

Because datasets generated by `ImportEngine` adhere to the identical manifest and Parquet standards as uploaded files:

1. **DuckDB Compatibility**: `SELECT * FROM read_parquet(['storage/datasets/.../part-*.parquet'])` executes instantaneously.
2. **Interactive Dashboards**: All KPI cards, Bar, Multi-line, Treemap, Scatter, Box-plot, and Heatmap widgets can immediately select and query the new dataset.
3. **Data Transformations**: Datasets can be joined, cleaned, or filtered inside Phase 4B transformation pipelines.
4. **AI & Gemini Interpretations**: Ask Your Data and Business Insight Engine query the dataset transparently.
